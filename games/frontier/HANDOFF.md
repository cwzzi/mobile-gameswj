## 2. 지금까지 구현된 주요 내용 (최신 `main` 기준)

### A. 전용 실사 3D 마을 내부 거리 씬 (`town3d.js`, `MODE === 'town'`)
- **비주얼 레퍼런스**: `https://www.taipei-rush.app/seoul/?region=seoul&lang=ko` (서울 러시 스타일의 3인칭 거리 시점·보도블록·간판·노점·움직이는 차량·원형 미니맵)
- **진입/퇴장**:
  - 오버월드에서 내 마을에 걸어 들어가면 자동 진입 (`event.js` `freeTick`, 전투 중/퇴장 직후 3.5초는 제외)
  - 또는 `건설` 패널의 **`🏘️ 마을 거리로 들어가기`** 버튼으로 즉시 진입
  - 남문 밖으로 걸어 나가거나 우상단 **`↩ 월드로`** 버튼 (`ESC`)으로 복귀
- **실제 1m 스케일 거리 구조 & 시대별(0 부족 ~ 4 근대) 그래픽**:
  - 남문 → 중앙 대로(`8.4m`) + 3D 연석 양쪽 보도(`5.4m`) → 중앙 광장(모닥불/우물/움직이는 분수대) → 북쪽 영주관/성채
  - **시대별 바닥/건축**: 부족 흙길 → 고대 사암 판석 → 중세 호박돌 → 근세 화강암 → **근대 아스팔트(황색 복선·붉은 전용차로·횡단보도) + 회색 보도블록·적벽돌 띠·노란 점자블록 + 교차로 바닥 LED 신호등**
  - **건물·간판·소품**: Poly Haven 실사 GLB([assets/real/](assets/real/)) + 다층 상가 파사드(밤 창문 발광) + 가로/세로 한글 간판(`학당`, `병영`, `장터·상회`, `대장간`, `종로 상회` 등) + 주황색 **포장마차** & 의자 + 벤치 + 가로수/수목보호대 + 가로등
  - **도로 위 움직이는 탈것**: 고대~근세 말 끄는 마차 / 근대 클래식 자동차 양방향 주행 (밤 헤드라이트·테일라이트 발광, 플레이어 앞 안전 정지)
  - **HUD & 조작**: 원형 회전 거리 미니맵(`#townMap`), 영주 전신 3인칭 카메라, PC 마우스 화면 어디서든 드래그 시선 회전(`core.js`), 모바일 왼쪽 조이스틱/오른쪽 시선, 좌상단 시계(`#townHud`) 탭 시 **아침(09:30) → 노을(17:45) → 밤(21:30)** 전환
- **마을 내 게임성 루프 (들판·전투·저장 `localStorage` 완전 연동)**:
  1. **🍲 포장마차 · 주막 식사 버프 (`S.buffs`)**: 체력 완전 회복 + 3분간 이동속도 `+22%` 또는 공격력 `+25%` (`world.js`, `battle.js` 연동)
  2. **🔨 대장간 영주 장비 강화 (`S.gear`)**: 무기(공격력↑), 갑옷(최대 체력↑), 군마(이동속도↑) 최대 `+5` 영구 강화
  3. **❗ 주민 민원 통치 선택지 (`t.petYear`)**: 매년 1명 황금 `!` 주민 등장 → 교역 투자(금 2배 도전) / 떠돌이 명장 영입(`S.artisan++`, 왕국 전체 자원 생산력 영구 `+8%`) / 장날 축제 후원 등 선택지
  4. **✨ 숨겨진 황금 보물 (`t.chestYear`)**: 매년 1회 골목·광장 구석에 출현 (18m 근접 힌트, 금화 + 경험치)
  5. **👑 마을 순시 민심 보너스 (`t.moraleT`)**: 주민 2명 이상 대화 또는 민원 해결 시 4분간 해당 마을 세금 수입 `+25%`
  6. **🐴 말 타고 마을 산책**: `🐴 승마` 버튼(또는 `R` 키)으로 대로에서 기마 주행

### B. 공용 3D 그래픽 업그레이드
- **`r3d.js`**: 공용 절차적 하늘 돔 `R3D.sky(scene)` 추가 (지평선–천정 그라데이션, 해/달 원반·산란 광륜, 흐르는 구름, 밤 별빛)
- **`post3d.js`**: Karis 휘도 가중 블룸 프리필터(반짝임 안정화), 부드러운 S-커브 대비
- **`real3d.js`**: 건물 바닥 접지 AO, 창문 낮 하늘 프레넬 반사, 나무 수관 하단 음영, 풀/꽃 카드 바람 흔들림, `medium` 품질 이상에서 건물 노멀맵 활성화
- **`world3d.js`**: 하늘 돔 연동, 들판 구름 그림자, 텍셀 스냅 그림자 카메라, 오버월드 마을 중심 광장 바닥 포장

## 3. 핵심 파일 구조
| 파일 | 역할 |
|---|---|
| `index.html` | UI/HUD 스타일, 패널(`#townPanel`, `#buildPanel` 등), 스크립트 로드 |
| `core.js` | 공용 유틸, 입력(조이스틱·탭·마우스/터치 시선 회전), 파티클 |
| `r3d.js` | Three.js 렌더러, 공용 재질, `R3D.human`/`R3D.horse`/`R3D.sky` |
| `post3d.js` | HDR HalfFloat + Dual-Kawase 블룸 + ACES + 품질(`high`/`medium`/`low`) |
| `assets3d.js` / `real3d.js` | KayKit / Poly Haven 실사 `.glb` 모델 & PBR 지면 로더 |
| `world.js` / `world3d.js` | 오픈월드 규칙·저장(`frontier-save-v1`) 및 3D 오버월드 렌더러 |
| **`town3d.js`** | **전용 실사 3D 마을 거리 씬 + 마을 성장/통치 게임성 루프** |
| `battle.js` / `battle3d.js` / `battleEra.js` | 대규모 액션 전투 규칙 및 시대별 전장 3D 렌더러 |
| `era.js` / `tech.js` / `kingdoms.js` / `event.js` | 시대·왕조, 기술/군대, 이웃 왕국 외교, 사건/소식판 |
| `main.js` | 메인 루프(`MODE`: `'world' | 'town' | 'battle'`), `window.__game` 디버그 훅 |

## 4. 로컬 개발 & 테스트 방법
```bash
# 저장소 루트에서 정적 서버 실행
python -m http.server 8765 --bind 127.0.0.1
```
- 브라우저 접속: `http://127.0.0.1:8765/games/frontier/?gfx=high&time=9.5`
- 콘솔 디버그 훅:
  - `__game.newGame({ era: 4 })` (0 부족 ~ 4 근대 즉시 시작)
  - `__game.enterTown(0)` / `__game.exitTown()`
  - `__game.setTime(21.5)` (시각 변경)
